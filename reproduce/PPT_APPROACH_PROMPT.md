# 可直接交给 PPT 制作 agent 的提示词：MAPF-Fuzz 方法流程

请为课程汇报制作一组介绍 **MAPF-Fuzz 的 Approach（论文 §3）** 的幻灯片。目标听众了解基本路径规划，但未读过论文。请用准确、简洁的中文，保留必要英文术语和数学符号。建议用 4–5 页讲清楚「整体闭环 → 地图/智能体变异 → 蜕变关系与判错 → 评价与能量选种」，每页只突出一个核心问题。下述内容已经核对论文及本项目实现，请不要省略方法类别，也不要把“变异”和“蜕变变换”混为一谈。

## 0. 统一记号与整体闭环

- **MAPF 任务/种子**：`I=(M,{(s_i,g_i)}_{i=1}^n)`；`M` 是有障碍的栅格地图，`s_i,g_i` 是第 `i` 个智能体的起点和目标。求解器 `A` 返回无碰撞轨迹 `π_i`；路径可原地等待，不能发生同格顶点冲突或对向交换边冲突。
- **SOC（Sum of Costs）**：`SOC(A(I)) = Σ_i T_i`，其中 `T_i` 是智能体 `i` 最终到达并保持在目标的时间步；智能体可能先到目标、再离开给其他智能体让路。它是**所有智能体路径到达成本之和**，不是最晚到达时间 `makespan=max_i T_i`，也不是求解器运行秒数。
- **闭环**：初始化种子池 → 按能量选父种子 → 地图级或智能体级变异生成新任务 → 基础可行性过滤 → 构造蜕变任务并成组运行目标求解器 → 检查失败、计算评分 → 将合格的新任务加入种子池。最终记录失败案例与统计。可以画成带回环箭头的流程图，变异、蜕变、评价用三个不同颜色模块。
- **术语区分**：变异（mutation）用于探索新的任务，**不要求**新任务与父种子有相同 SOC；蜕变变换（metamorphic transformation）在已生成的新任务上构造有关联的对照任务，用于检查求解器是否一致。

## 1. 变异阶段：构造有挑战性的 MAPF 任务（论文 §3.2）

### 1.1 地图级变异（Map-Level Mutation）

1. 用上一轮求解轨迹统计智能体通行/等待频率，识别**热点区域**，仅修改少量等尺寸局部 patch，避免整图随意翻转障碍。本复现使用完整等待频率图，选最多 3 个互不重叠的 `32×32` 热区；这是实现参数，不是论文定义本身。
2. 生成候选 patch 的三类方法：
   - **Random Patch**：随机二值障碍图。论文列均匀噪声与 Perlin 噪声；本复现依据作者代码实际可达分支，仅在这一类使用均匀噪声。
   - **Cellular Automata（CA）Patch**：先由均匀/Perlin 噪声初始化，再基于 **8 邻域**的出生/存活规则迭代，形成走廊、团块、房间等结构；包含 Conway、HighLife、Maze、Mazectric、WalledCities 等规则。本复现补齐作者 26 个预设，其中 8 个由 Perlin 初始化，因此**不能说“整个项目没有 Perlin”**。
   - **Fractal Patch / DLA（Diffusion-Limited Aggregation）**：从可通行 patch 出发，随机游走粒子按 **4 邻域**移动并黏附于已有障碍，逐渐生成树枝状障碍，直到目标密度或游走上限。
3. 将原区域 `A₁` 与新 patch `A₂` 按障碍集合做 7 种组合：`A₂`（替换）、`A₁∪A₂`、`A₁∩A₂`、`A₂\A₁`、`A₁\A₂`、`¬A₁∪A₂`、`¬A₂∪A₁`。图示可用同一块局部地图展示“原图 → 新 patch → 组合后地图”。集合符号表示障碍格集合，补集相对于 patch 范围。

### 1.2 智能体级变异（Agent-Level Mutation）

- **无引导（unguided，探索）四类**：① 随机选择部分智能体交换起终点（Start–Goal Inversion）；② 在智能体间随机重排全部起点或全部终点（Start/Goal Position Permutation）；③ 以一定概率独立搬移每个起点/终点到可通行格（Stochastic Endpoint Relocation）；④ 在同一地图上重新生成整组起终点（Full Agent Regeneration）。
- **引导式（guided，利用运行反馈）四类**：① **Local Shift**：在局部窗口移动热点智能体端点；② **Shadow Injection**：添加起终点接近某个 leader 的跟随智能体；③ **Counter-flow Injection**：添加与已有智能体大致反向行进的智能体；④ **Congestion Injection**：把新智能体起终点放在拥堵区两侧，使其穿越热点。新增智能体后随机移除等量原智能体，保持总数 `n` 不变。
- 本课程复现仅实现论文列出的上述四种引导操作；作者源码另外的 appointment/naughty 注入未纳入本次范围。展示时可用一张「无引导 vs 引导」对照示意图：左侧改变端点分布，右侧叠加路径热力图和四种干扰方向。

### 1.3 两阶段可解性检查

1. **廉价结构过滤**：所有起终点必须在可通行格；对每个智能体，起点和目标在地图的同一连通分量。此条件仅排除明显无效任务，**不能证明多智能体同时可解**。
2. **蜕变推断**：若等价对照任务有解，可推断源任务理论上可解；若两者均未解，则证据不足，保守丢弃。该推断复用下一阶段已有求解结果，无需额外求解器调用。PPT 上用“必要条件过滤 → 成组对照推断”两级漏斗表示。

## 2. 蜕变阶段：构造关联任务并判断求解器（论文 §3.3）

- 对变异后的源任务 `I`，用蜕变关系 `T_j` 构造 `I′_j=T_j(I)`。**等价任务的含义**是它们在对应 MR 的预期性质下具有相同的可解性；对于支持 SOC 不变性的 MR，若均有解，还预期其 SOC 一致。论文以此取代求真实最优解作为测试 oracle。
- **C1：可解性一致**，`Solved(A(I)) ⇔ Solved(A(T_j(I)))`。一边有解、一边未解即 **CF（Completeness Failure，可解性失败）候选**；必须在相同求解器设置和超时限制下解释。
- **C2：SOC 不变**，当两边都有解时 `SOC(A(I)) = SOC(A(T_j(I)))`。严重偏离记为 **OF（Optimality Failure，最优性失败）候选**。C2 只用于声称支持 SOC 对照的关系。

| 蜕变关系 | 构造方式 | 理论检查 |
| --- | --- | --- |
| `MRrevOrd` | 随机重排输入中的智能体顺序，地图和每个 `(s_i,g_i)` 不变 | C1 + C2 |
| `MRfliplr`、`MRflipud`、`MRflip180` | 地图、障碍、所有起终点一起左右镜像、上下镜像、旋转 180° | C1 + C2 |
| `MRaddIrrObs` | 根据轨迹热图，在原路径附近但路径外加入障碍 | 论文纳入 C1 + C2 |
| `MRprobe` | 根据热图添加起终点相邻的一步探测智能体，提高局部密度 | 论文纳入 C1 + C2 |
| `MRswap` | **每个**智能体各自交换起点和目标，保持地图 | **只检查 C1** |

- 一组原任务最多配 **7 个蜕变任务**：顺序 1 + 几何 3 + 加障碍 1 + probe 1 + swap 1。用于 SOC 差异的集合是**原任务 + 前六种变换**，`MRswap` 不参加 SOC 的 MD 计算，因为交换方向只保证可解性对应，不保证 SOC 一致。
- **Metamorphic Disparity（MD）**：对可比较且求解成功的 `SOC_list`，`MD = [max(SOC_list) − min(SOC_list)] / min(SOC_list)`。论文实验以 `τ=25%`，`MD>τ` 报 OF。MD 是不同蜕变结果间的**代理差异/最优差距下界**，不能宣称已求得真正最优 SOC。
- **必须在备注中保留的局限**：probe 增加智能体会天然增加 SOC；加障碍也可能改变最短可行路径。因此把两者的**原始 SOC**直接并入 C2/MD，存在严格不变性解释上的争议。本课程按论文和作者代码口径纳入，并额外记录 `probe SOC − 原 SOC − 新增 probe 的一步基础成本` 作诊断；正式图表应标注“按论文/作者口径的 MR 差异”，避免把每个 OF 都说成数学上已证实的最优性错误。`MRrevOrd` 本复现按论文文字随机重排；作者代码实际固定反转。地图热点求和与 Critical Score 的路径格判断也按论文语义修正，详见末尾说明。
- 如果演讲时间紧，主页面仅画 3 个代表性的对照图：输入顺序、整图镜像、热点加 probe；旁边表格列出完整 7 个变换，突出 `MRswap → C1 only`。

## 3. 评价阶段：判错、种子能量和反馈（论文 §3.4）

### 3.1 四项评分因素

1. **MD（蜕变差异）**：上式衡量同组任务输出 SOC 的最大相对差。数值越大，表示目标求解器在相关 MR 下越不一致。
2. **C（Critical Score，关键性）**：定义四个比例：
   - `R_AW`（Agent Waiting Ratio）=`等待显著高于平均的智能体数 / n`；
   - `R_AD`（Agent Detour Ratio）=`实际行进长度显著超过单智能体最短路的智能体数 / n`；
   - `R_MU`（Map Cell Usage Ratio）=`被占用频次显著高的地图格数 / 可通行格数`；
   - `R_MW`（Map Cell Waiting Ratio）=`等待频次显著高的地图格数 / 可通行格数`。
   论文公式 `C = α₁R_AW + α₂R_AD + α₃R_MU + α₄R_MW`，`Σαᵢ=1`，且 `α₁=α₂=2α₃=2α₄`，所以可写成 **`C=(R_AW+R_AD)/3 + (R_MU+R_MW)/6`**。论文只说“显著/远高于”，本复现具体采用 `>2×`：智能体等待比平均等待、实际行进长度比自己的单智能体最短路、格子使用/等待频次比全图格平均频次。PPT 若列 `2×`，必须标作“本复现阈值”，不能说论文给出了该精确阈值。
3. **P（MR Failure Frequency Penalty，关系失败频率惩罚）**：每个 MR 维护违反次数 `v_j` 与软配额 `q_j`；`W_j=1 (v_j≤q_j)`，`W_j=β^(v_j−q_j) (v_j>q_j, 0<β<1)`。每轮只对差异最大的违规 MR 更新计数；论文表达为当前关系的 `P=W_j`，目的是避免持续偏向同一种容易触发的关系。本复现取 `q_j=5, β=0.95`。
4. **S（Task Similarity Score，实际是新颖度权重）**：抽取地图、智能体配置、求解行为特征；标准化后查询已接收种子的最近邻距离 `d`。`d<Q₁ → S=0.5`，`Q₁≤d≤Q₃ → S=1.0`，`d>Q₃ → S=1.5`；`Q₁,Q₃` 是距离分布的第 1、第 3 四分位。虽然名称是 similarity，**距离越大、S 越高，表示越新颖**。论文使用 ANN 索引；本机测试用精确最近邻，服务器长跑用 Annoy 近似检索。近似检索可能改变选种顺序，但不改变评分定义。

### 3.2 16 维特征怎样组成

PPT 可画 3 段并排条形标记 **3 + 8 + 5 = 16 维**，避免写成 15 维：

- **地图 3 维**：可通行格比例（对应障碍密度）、到障碍的平均距离、死胡同数量。
- **智能体配置 8 维**：单智能体最短路长度的均值与标准差 2 维；起点 DBSCAN 聚类摘要 3 维；终点 DBSCAN 聚类摘要 3 维。论文概述为“最短路长度分布与起终点空间聚类”，具体 16 维拆法取自复现/作者实现。
- **动态运行 5 维**：总实际行进长度/总最短路长度 1 维；绕行系数均值、标准差 2 维；等待时间均值、标准差 2 维。

### 3.3 论文公式与本课程代码必须分开讲

- **论文 §3.4 的概念公式**：`E_paper = (MD × P + C) × S`。高能量种子更可能被选中继续变异。
- **当前复现按作者实现的实际选种分数**：对每个支持 SOC 的 MR 计算 `δ_j=|SOC_j−SOC_original|/SOC_original` 和 `W_j=0.95^max(0,v_j−5)`；取 `D=max_j(δ_j W_j)`。再定义长度因子 `L=2/[1+exp{−0.03(SOC_original/n−0.8×128)}]`。对合格的后续变异种子，**`E_impl=(0.2 C + D) × S × L`**；初始已解种子 `E_init=0.4 C`。父种子按最大 `E_impl` 选择，被选一次后能量乘 `0.9` 防止重复选中。**不要把 `E_impl` 冒充论文原式**；若主讲页只讲论文，可把此段移至“复现口径”备份页。
- 原任务/关系求解输出不合法、CF、以及后续变异得到的 OF 任务按当前实现不作为新父种子；已确认的失败仍保存统计和案例。评价阶段的产物可以画成「失败日志」与「更新种子池」两个出口。
