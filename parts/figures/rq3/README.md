# RQ3 正式实验图表说明

数据源：`reproduce/output/rq3/20261120T040544.559020Z/` 下四个求解器的 `summary.json` 与 `manifest.json`。四作业均为 128×128、100 agents、Annoy、单 worker、初始化后运行约一小时；`stop_reason=time_limit`，初始化后计时缺失数为 0。图中数值均来自真实正式批次。

- `rq3_phase_share.svg/png`：方法介绍后的 RQ3 **主结果页**。回答四个求解器在哪个阶段耗时最多。分母只包含四个互斥阶段；这是对论文图 6 的**近似复现**，因为本实现的结果解析还验证轨迹，且使用检查点。
- `rq3_absolute_time.svg/png`：主图之后的**解释页或备份页**。回答百分比之外实际花了多少秒，以及还有多少未归因墙钟时间。墙钟残余混合检查点、调度等开销，不能当成精确检查点时间。
- `rq3_execution_detail.svg/png`：**备份页**，或讲 LaCAM* 与其他求解器差异时接在主图后。`solver` 与 `result_parse` 是 `execution` 的子项，图中只在执行阶段内拆解；结果解析含轨迹校验。

汇报时可说：PIBT、HCA、PIBT+ 的结果分析约占四阶段总时间的一半；LaCAM* 的执行阶段占 92.8%，其中约 97.5% 是求解器进程。四个求解器初始化后分别完成 1340、1150、1304、133 组。每个求解器仅运行一次，图中不加误差线；不要把占比差异解释为严格的论文实现差异或求解器优劣。
