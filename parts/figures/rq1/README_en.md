# RQ1 main-experiment figures (English)

Source: `reproduce/output/server/20261120T085856.450113Z`, its 20 job summaries/manifests, `rq1_compact.jsonl.gz` (94,082 formal case records), and the two retained cases named below. All 20 jobs reached `time_limit` without processing or dispatch errors. The formal server acceptance reported 20 jobs, 94,082 unique task groups, and 0 errors/warnings. Every figure uses this formal run, never the preflight data.

- `rq1_counts_five_runs_en.svg/png` — **Main RQ1 results slide.** Exact CF and OF flag counts for each of five repetitions of four solvers. The two heatmap color scales are separate; numbers in cells are authoritative. Show the five-run variation before discussing any totals. LaCAM* ran 6 hours per repetition; the others ran 1 hour per repetition. Raw counts are not defect rates.
- `rq1_rates_per_1000_en.svg/png` — **Follow-up slide.** Pooled flags per 1,000 completed task groups, with each solver's pooled number of groups shown. This adjusts for different task-group exposure but does not control for solver-specific task distributions or different run durations. The CF and OF axes use different ranges.
- `rq1_cumulative_flags_en.svg/png` — **Discovery-timing slide.** Mean cumulative flags across five runs per solver. The x-axis is a fraction of each run's actual fuzzing duration, so LaCAM*'s six hours and the others' one hour are not presented as the same number of elapsed minutes. Five PIBT CF flags from the initial pool appear at 0%. The count heatmap shows run-to-run variation that the mean curve hides.
- `rq1_mr_associations_en.svg/png` — **Method-to-finding slide.** Left: every CF relation whose solved/unsolved status disagrees with the original; 346 CF groups yield 599 relation associations because one group can involve several MRs. Right: the single `violating_mr` label for each of 83 OF groups, used by the scoring logic. These labels are descriptive, not causal proof; `swap_start_goal` checks solvability only. Probe/obstacle SOC comparability is debatable.
- `rq1_md_threshold_en.svg/png` — **Threshold-severity slide.** Among 94,005 groups with numeric MD, 83 exceed 25%; 74 of those lie between 25% and 30%. The two extreme LaCAM* cases reach about 886% and 3,206%. Bars are counts in unequal categorical bands, not a density histogram. A separate strict check of original + order/flip MRs still exceeds 25% in 37 OF groups.
- `rq1_map_lineage_en.svg/png` — **Exploration/limitations slide or backup.** Initial pool cases (`case < 90` in each job) cover 30 source maps uniformly. Of 90,843 selected-parent child cases (`parent_case != null`), 99.5% inherit Denver_0, Paris_2, or London_2 as `map_source`. This is a source-map *lineage* field: a map mutation can change the actual grid. The 1,439 later random-fallback cases with `parent_case = null` are excluded from both bars.
- `rq1_case_cf_swap_en.svg/png` — **Concrete C1 example.** Formal HCA run 1, case 1,262. The saved map is identical in the original and `swap_start_goal` runs, and all 100 start/goal pairs are reversed. The original is solved (SOC 10,687), while the swapped task is reported unsolved; the other six MRs are solved. The one displayed agent pair comes from `input.txt`, but no path trace is shown.
- `rq1_case_of_flip_en.svg/png` — **Concrete C2/MD example.** Formal LaCAM* run 4, case 3,901. The saved `up_down` map is an exact vertical mirror of the original. All three shown runs are solved: order SOC 11,919, original 12,706, up-down flip 16,132. Their strict order/flip comparison yields MD = 35.35% > 25%, without using probe or obstacle SOC. The map panels are actual saved inputs; no individual-agent path cause is asserted.

CF and OF are independent metamorphic flags and could overlap in a task group. In this formal batch, inspection of all 94,082 compact rows found **zero overlaps**: 346 CF groups and 83 OF groups, 429 distinct flagged groups. A flag is not a traced root cause or a proof of the optimal SOC. The map and SOC example slides are concise on purpose: overlaying 100 agent trajectories would obscure the verified relationship.
